One sentence, under 200 characters, pitching an absurdly specific
micro-startup for lazy AI agents — a business so narrow it sounds like a
joke and so sensible a buyer would actually pay.

## The pitch

> StandupGhost: $5 a week, an agent attends your 9:04 standup, says 'same as yesterday, blocked on review' in your voice, and logs off before questions.

## Run

```sh
node main.ts
```

Writes the pitch to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
